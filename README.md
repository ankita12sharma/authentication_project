# 🔐 Authentication System (MERN Stack)

A full-stack authentication system built using the **MERN stack (MongoDB, Express, React, Node.js)**.
The application implements secure user authentication with **JWT-based authorization**, along with protected routes for access control.

The project follows a **modular MVC architecture** on both frontend and backend to ensure clean code organization and scalability. On the frontend, **Redux Toolkit (RTK Query)** is used for efficient API handling, caching, and state management.

---

## 🚀 Key Highlights

* 🔐 Secure authentication using JWT
* 🧱 Structured using MVC architecture
* ⚡ Efficient API handling with RTK Query
* 🔄 Real-time state updates and caching
* 🔒 Protected routes with token validation
* 🎯 Clean and scalable project structure

---

## ✨ Features

* ✅ User Signup & Login
* 🔐 JWT Authentication
